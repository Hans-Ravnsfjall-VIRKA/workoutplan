How to pace it

Most runs should feel easy: you can hold a conversation.

  • Easy pace: around 7:45–8:30 /km
  • Long run pace: around 8:00–9:00 /km
  • When in doubt, go slower.
The knee rule
  • 0–3 / 10: fine, as long as it does not get worse.
  • 4–5 / 10: reduce or stop the session.
  • Sharp pain, limping, swelling, locking, instability, or worse pain the next day. Stop running and consider seeing a physio.
Run / walk

Use it whenever you need to. Two options:

  • 9 min run / 1 min walk
  • 4 min run / 1 min walk on harder days
Strength session

Twice a week, 25–35 min. Keep everything controlled and pain-free. Tap an exercise for a demonstration.

  • Glute bridges: 3 × 12
  • Step-ups: 3 × 8 each leg
  • Romanian / light deadlift: 3 × 8–10
  • Calf raises: 3 × 12–15
  • Side plank: 2 × 30 sec each side
  • Banded side steps (optional): 2 × 12 each side
If the knee gets worse
  • Replace the next run with bike or spinning.
  • Repeat the same week instead of adding distance.
  • Do not increase the long run until the knee is stable again.

Priorities, in order: stay injury-free, build the long run, lose weight gradually, improve speed later.
